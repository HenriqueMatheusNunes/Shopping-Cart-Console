# Carrinho de Compras em C# (Console Application)

Aplicação interativa desenvolvida em console utilizando **C#** e **.NET**, focada na prática de Programação Orientada a Objetos (POO), manipulação de coleções em memória e estruturas de controle de fluxo.

Funcionalidades
- **Adicionar Produto:** Cadastro de produto com nome, preço e quantidade em estoque.
- **Listar Produtos:** Exibição dos itens no carrinho com cálculo automático de subtotal por item.
- **Remover Item:** Remoção de item específico via índice com validação de entrada (`int.TryParse` e limites da lista).
- **Calcular Total:** Cálculo acumulado do valor total de todos os itens cadastrados.
- **Limpar Carrinho:** Esvaziamento total da lista de compras.
